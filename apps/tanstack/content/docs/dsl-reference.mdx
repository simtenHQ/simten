## Circuit Definition

Circuits are defined in TypeScript using the `circuit()` builder:

```typescript
import { circuit, bus, bit } from '@turing-incomplete/core/circuit'
import { Xor, And } from '@turing-incomplete/core/std'

const HalfAdder = circuit('HalfAdder', {
  in:  { a: bit, b: bit },
  out: { sum: bit, carry: bit },
  nodes: { xor1: Xor, and1: And },
  connect: ({ in: inp, out, xor1, and1 }) => [
    inp.a.to(xor1.a, and1.a),
    inp.b.to(xor1.b, and1.b),
    xor1.out.to(out.sum),
    and1.out.to(out.carry),
  ],
})
```

## Types

| Helper | Description | Runtime representation |
|--------|-------------|----------------------|
| `bit` | Single binary value | `boolean` (0 or 1 internally) |
| `bus(N)` | N-bit wide bus | `number` (unsigned, max 32 bits) |

```typescript
import { bus, bit } from '@turing-incomplete/core/circuit'

const MyCircuit = circuit('MyCircuit', {
  in:  { addr: bus(16), enable: bit },
  out: { data: bus(8) },
  // ...
})
```

## Circuit Config

```typescript
circuit(name, {
  in?:       Record<string, PortType>     // named input ports
  out?:      Record<string, PortType>     // named output ports
  meta?:     { description?: string }     // shown in palette / used by Claude
  nodes:     Record<string, ComponentClass>   // node label → component type
  nodeArgs?: Record<string, object>           // parameters per node
  connect:   (refs) => Connection[]           // wiring
})
```

## Connections

The `connect` function receives refs for all inputs, outputs, and nodes. Call `.to()` to wire ports:

```typescript
connect: ({ in: inp, out, xor1, and1 }) => [
  inp.a.to(xor1.a, and1.a),    // fan-out: one source to multiple targets
  inp.b.to(xor1.b, and1.b),
  xor1.out.to(out.sum),
  and1.out.to(out.carry),
]
```

Connections are directional: source (left) drives target(s) (right). A port can drive multiple targets (fan-out), but each input can only have one driver.

## Node Parameters

Pass parameters in `nodeArgs`:

```typescript
nodes:    { reg: Register, k: Constant, add: Adder },
nodeArgs: {
  reg: { initial: 0, width: 8 },
  k:   { value: 42, width: 8 },
  add: { width: 8 },
},
```

| Parameter | Used by | Description |
|-----------|---------|-------------|
| `width` | Adder, Comparator, Mux, etc. | Bus width (default: 8) |
| `value` | Constant, Input, Switch | Fixed or initial value |
| `initial` | Register | Initial state value (default: 0) |
| `init` | RAM, DualPortRAM, ROM | Memory initialization map `{ addr: value, ... }` |
| `low`, `high` | BitSlice | Bit range to extract (inclusive) |
| `baseAddress` | ROM | Memory-mapped base address |

## Composition

Circuits compose by using one circuit as a node in another:

```typescript
const FullAdder = circuit('FullAdder', {
  in:  { a: bit, b: bit, cin: bit },
  out: { sum: bit, cout: bit },
  nodes: { ha1: HalfAdder, ha2: HalfAdder, or1: Or },
  connect: ({ in: inp, out, ha1, ha2, or1 }) => [
    inp.a.to(ha1.a),
    inp.b.to(ha1.b),
    ha1.sum.to(ha2.a),
    inp.cin.to(ha2.b),
    ha2.sum.to(out.sum),
    ha1.carry.to(or1.a),
    ha2.carry.to(or1.b),
    or1.out.to(out.cout),
  ],
})
```

The simulator **elaborates** composites by recursively flattening them to primitives. A `FullAdder` node becomes two `Xor`, two `And`, and one `Or` node internally — composites have zero runtime overhead.

## Self-contained Demos

Circuits without `in`/`out` ports are treated as top-level demos. Use `Input`, `Switch`, and `HexDisplay` for interactive elements:

```typescript
import { Input, HexDisplay, Adder } from '@turing-incomplete/core/std'

const AdderDemo = circuit('AdderDemo', {
  nodes: { a: Input, b: Input, add: Adder, disp: HexDisplay },
  nodeArgs: { a: { value: 10 }, b: { value: 5 }, add: { width: 8 }, disp: { width: 8 } },
  connect: ({ a, b, add, disp }) => [
    a.out.to(add.a),
    b.out.to(add.b),
    add.sum.to(disp.in),
  ],
})
```

## Type Rules

- `bit → bit` — valid
- `bus(N) → bus(N)` — valid (same width)
- `bit → bus(N)` — invalid (needs explicit conversion)
- `bus(8) → bus(16)` — invalid (width mismatch)

Use `Splitter`, `BitSlice`, or `Concat` for type conversions.
