Turing Incomplete is a browser-based platform for learning digital hardware design. You write circuits in a structural DSL, see them rendered live on an interactive canvas, and simulate them with time-travel debugging. An AI tutor (Claude) can help you build, debug, and understand circuits in real time.

## What you can build

Everything runs in the browser — no toolchain, no installation, no FPGA required.

- **Logic gates and adders** — start from AND, OR, XOR and build up to full adders and ALUs
- **Sequential circuits** — counters, shift registers, state machines using registers and flip-flops
- **Games in hardware** — [Snake](/blog/snake-in-hardware) and [Pong](/blog/pong-in-hardware), built entirely from logic gates with no CPU
- **A complete CPU** — a [5-stage pipelined RISC-V processor](/blog/building-a-cpu) that runs compiled C code
- **Accelerators** — a [TPU systolic array](/blog/how-tpus-work) doing matrix multiplication, a [CORDIC unit](/blog/computing-trig-in-hardware) computing trigonometry
- **Networking hardware** — an [Ethernet switch](/blog/how-network-switches-work) with frame parsing, buffering, and forwarding

## AI tutor with Claude Code

Connect Claude Code to get an AI tutor that can see your circuit, push changes to the browser, run simulations, and answer questions in real time:

```bash
claude mcp add turing-incomplete npx @turing-incomplete/mcp
```

Ask Claude to build a counter, debug your ALU, or walk you through a challenge — it writes the DSL and the circuit appears on your canvas instantly.

See the [Claude Code Integration](/docs/claude-code) guide for the full setup, available tools, and how the bidirectional MCP bridge works.

## Packages

| Package | Description |
|---------|-------------|
| `@turing-incomplete/core` | DSL parser, compiler, validator, simulator engine |
| `@turing-incomplete/ui` | React components for rendering and interacting with circuits |
| `@turing-incomplete/mcp` | MCP server for Claude Code integration |
| `@turing-incomplete/challenges` | Educational challenge definitions (ALU, Snake, CPU) |
| `@turing-incomplete/cli` | Command-line interface |

### UI sub-paths

```
@turing-incomplete/ui/embed   — CircuitEmbed, useCircuitSimulator
@turing-incomplete/ui/shared  — CircuitCanvas, WaveformViewer, TestResultsPanel
@turing-incomplete/ui/editor  — Full editor kit (stores, components, simulation controller)
```

## Embed a circuit

Drop an interactive circuit into any React app:

```tsx
import { CircuitEmbed } from '@turing-incomplete/ui/embed';

<CircuitEmbed
  dsl={`circuit HalfAdder {
    input a: Bit
    input b: Bit
    output sum: Bit
    output carry: Bit
    impl {
      node xor1: Xor
      node and1: And
      connect a -> xor1.a
      connect b -> xor1.b
      connect xor1.out -> sum
      connect a -> and1.a
      connect b -> and1.b
      connect and1.out -> carry
    }
  }`}
  height={250}
  showControls
  autoHarness
/>
```
