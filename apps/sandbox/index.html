Simten sandbox

This origin runs circuit code in isolation for simten.dev, play.simten.dev, and anything embedding Simten circuits. It exists as a separate origin so that the code it runs cannot reach the pages that host it.

On its own it does nothing. It executes only what a parent page sends it over postMessage, so opening this address directly runs no code at all.

Source: github.com/simtenHQ/simten. Security policy: SECURITY.md.
